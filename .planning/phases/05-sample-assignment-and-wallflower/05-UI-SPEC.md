## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge inner padding, separator dots |
| sm | 8px | Compact element spacing, assign button inner gap |
| md | 16px | Default element spacing, card/panel padding |
| lg | 24px | Section padding, dialog internal spacing, Wallflower panel header |
| xl | 32px | Layout gaps between slot list and Wallflower panel |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Assign button on SlotRow: 32px tall (h-8) to match the toolbar button convention from Phase 4
- Slot picker dialog bank cells: 48px × 48px (w-12 h-12) — matches BankGridCell / BankCopyPickerDialog established pattern
- Touch targets (all interactive controls): minimum 44px per WCAG 2.5.5
- Wallflower sample row height: 36px (h-9) — slightly taller than SlotRow (h-8) to accommodate two lines of badge content at compact spacing

Source: `MetadataHeader.tsx` (h-8 toolbar), `BankCopyPickerDialog.tsx` (w-12 h-12 grid cells), `sidebar-nav.tsx` (44px enforcement per STATE.md Plan 01-06).

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 14px (text-sm) | 400 regular | 1.5 | Iosevka mono |
| Label | 12px (text-xs) | 400 regular | 1.4 | Iosevka mono |
| Heading | 16px (text-base) | 600 semibold | 1.2 | Iosevka mono |
| Display | 24px (text-2xl) | 600 semibold | 1.2 | Iosevka mono |

Notes:
- Monospace is the default for all UI text (globals.css body font-family: var(--font-mono)) — unchanged from Phases 1–4
- Proportional (Inter sans) reserved for: modal operation summaries (dry-run summary line), longer descriptive text — matching `DryRunModal.tsx` fontFamily pattern
- Tabular-nums class required on all numeric data (slot indices, file counts, BPM values, file sizes)
- Section headings ("FLEX SAMPLES", "STATIC SAMPLES", "WALLFLOWER LIBRARY") use text-lg (18px) font-semibold — matches existing SamplesTab pattern
- Wallflower sample BPM and key values render in text-xs tabular-nums (these are always numeric)

Source: `globals.css`, `SamplesTab.tsx` (text-lg section headings), `DryRunModal.tsx` (var(--font-sans) for summary), `SlotRow.tsx` (text-xs labels). Unchanged from Phase 4 UI-SPEC.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | hsl(30 8% 10%) — `--background` | Main content area, page surfaces |

Accent reserved for:
- Active tab underline indicator (border-b-2 on selected TabsTrigger)

- Primary CTA button background ("Assign Sample", "Push to Slot", "Apply")
- Focus ring (--ring)
- Sidebar active section indicator
- Wallflower sample row selected state left border (border-l-2 border-[hsl(38,85%,55%)])
- Occupied slot indicator in slot picker (reuses BankCopyPickerDialog amber warning pattern)

Semantic colors carried forward from Phase 3/4:
- Success state (inline assignment success banner): hsl(140 30% 14%) background, hsl(140 60% 72%) text — matches `InlineSuccessBanner.tsx` exactly
- Added file indicator: hsl(140 60% 42%) — green, DryRunModal file list
- Modified file indicator: hsl(38 85% 55%) — amber/accent, DryRunModal file list
- Removed file indicator: hsl(0 68% 48%) — destructive red, DryRunModal file list
- Conflict file indicator: hsl(280 60% 55%) — purple, DryRunModal (carried from Phase 4 ConflictResolutionDialog)
- Soft warning (non-ideal format like 48kHz): hsl(38 85% 55%) — amber, inline warning text below slot row (not destructive red — deliberate distinction from hard block)

Source: `globals.css`, `InlineSuccessBanner.tsx`, `DryRunModal.tsx` (changeTypeColor), Phase 4 `04-UI-SPEC.md`. Unchanged.

## Component Inventory (Phase 5 New Components)

### Assign Button on SlotRow

Added to the right side of each slot row's fixed-width column area (after STATUS column). The existing expand-on-click-row-body behavior is preserved; the assign button is a distinct, separate target.

- Icon: `Upload` (lucide) — 14px, represents "push a file up/into" the slot
- Size: h-8 w-8 (32px square icon button)
- Variant: `ghost`
- Positioned: trailing column, `shrink-0 w-8` — always visible
- Aria-label: `"Assign sample to Flex slot NNN"` or `"Assign sample to Static slot NNN"`
- Click: opens native macOS file picker (Tauri `open()` dialog, WAV/AIFF filter applied)
- Empty slot: button always visible (assigns a new sample)
- Occupied slot: button always visible (triggers replacement flow with old→new dry-run preview)

SlotTableHeader gains a new rightmost column: `w-8 shrink-0` — no label (icon-only column, consistent with STATUS column pattern).

### Dry-Run Preview — Assignment Variant

Reuses existing `DryRunModal` component without modification. Phase 5-specific operation labels:

| Scenario | operationLabel value |
|----------|---------------------|
| Assign new sample to empty slot | "Assign FILENAME to Flex #NNN" |
| Replace sample in occupied slot | "Replace FILENAME_OLD → FILENAME_NEW in Static #NNN" |
| Push Wallflower sample to slot | "Push FILENAME from Wallflower to Flex #NNN" |

The summary sentence (displayed in Inter sans, 14px) for replacement reads:
`"Replacing kick_808.wav with new_kick.wav in Flex slot 003 — 18 files will be updated."`

The snapshot guarantee line is verbatim (carried from Phase 3 D-10):
`"A snapshot of the current state will be created before applying."`

### Slot Type Error Inline (Hard Block)

Displayed below the slot row when an incompatible assignment is attempted (SMPL-03 enforcement).

- Placement: immediately below the SlotRow that received the assign action, full row width
- Layout: `flex items-start gap-2 px-3 py-2 bg-[hsl(0,68%,12%)] border border-destructive rounded`
- Text: `text-xs text-destructive` — error explanation
- Action buttons: two inline buttons, `font-mono text-xs`, separated by `gap-2`:
  - Primary: `"Assign to Static #NNN"` (variant="default") — one-click redirect to the equivalent slot in the correct type
  - Secondary: `"Cancel"` (variant="ghost") — dismisses the error without action
- Dismissed automatically when: user clicks either button or navigates away

### Format Warning Inline (Soft Block)

Displayed in the dry-run preview modal's summary area (above the file list) when format is valid but non-ideal (e.g., 48kHz, 32-bit).

- Placement: between the snapshot guarantee line and the change summary strip in `DryRunModal`
- Layout: `text-xs text-[hsl(38,85%,55%)] italic py-1` — amber soft warning, visually subordinate to hard errors
- The existing modal CTA buttons remain: `"Don't Apply"` (ghost) and `"Assign Sample"` (default) — user can proceed past soft warnings

Hard block (incompatible format — MP3, FLAC, etc.) prevents the dry-run modal from opening. Error is shown as the Slot Type Error Inline pattern with destructive red text:
`"Unsupported format: OT accepts WAV and AIFF only. Convert this file first."`
No action button redirect (there is no equivalent correct slot for an incompatible format).

### Wallflower Panel

Collapsible section rendered below the Static Samples list in `SamplesTab`. Hidden entirely when Wallflower DB is unavailable (D-07).

**Panel structure:**

```
[ WALLFLOWER LIBRARY  ▼ ]          ← collapsible trigger, full width
[ Search/filter bar                ]  ← visible when panel is open
[ Sample result rows (scrollable)  ]
```

- Collapsible trigger: full-width `h-10` bar, `font-mono text-sm font-semibold uppercase text-foreground`, with `ChevronDown` / `ChevronUp` icon (16px, trailing, lucide)
- Default state: expanded (open) — Wallflower is a key feature; it should be immediately visible
- Session persistence: collapse state stored in zustand store, persists across project navigation within session (not persisted to disk)
- Trigger background: `bg-[hsl(30,8%,14%)]` (sidebar surface, visually distinct from panel rows)
- Panel background: `bg-[hsl(30,8%,16%)]` (card surface — `--card`)
- Panel max-height when open: `max-h-96` (384px) with `ScrollArea` for overflow

**Search/filter bar:**

- Single `<input>` element, `font-mono text-xs`, placeholder: `"Search by name, key, BPM, or tag…"`
- Full width, `h-8`, `bg-[hsl(30,8%,18%)]` (muted), `border border-border`, `rounded-sm`
- Debounce: 300ms — no minimum query length (single-character searches are valid for key, e.g., "C", "F#")
- Result limit: 200 rows (Wallflower libraries can be large; truncate with count indicator: `"Showing 200 of N — refine your search"`)
- Result sort: by filename ascending (default), no sort controls exposed in Phase 5

**Sample result row (WallflowerSampleRow):**

Layout: `flex h-9 items-center px-3 gap-2 border-b border-border`

Columns (left to right):
1. Filename: `font-mono text-xs text-foreground flex-1 min-w-0 truncate`
2. Key badge: `font-mono text-[10px] text-muted-foreground w-8 tabular-nums` — shows detected musical key (e.g., "C#4") or empty if null
3. BPM badge: `font-mono text-[10px] text-muted-foreground w-10 tabular-nums` — shows BPM (e.g., "120") or empty if null
4. Tag badges: `flex gap-1 shrink-0` — up to 3 tags shown as `<Badge variant="outline" className="font-mono text-[10px] h-4 px-1">`, overflow with "+N" count badge
5. Push button: `h-6 w-6` icon button, `Upload` lucide icon (12px), `variant="ghost"`, `shrink-0` — triggers push-to-slot flow

Selected row (after click on row body or push button):
- `bg-[hsl(30,8%,20%)] border-l-2 border-[hsl(38,85%,55%)]` — accent left bar + muted highlight

### Slot Picker Dialog (Push-to-Slot Flow)

Triggered when user clicks the Push button on a Wallflower sample row. Reuses `Dialog` component pattern from `BankCopyPickerDialog`.

- Title: `"Assign to Slot"` (font-mono text-base semibold)
- Sub-caption: `font-mono text-xs text-muted-foreground` — `"Pushing FILENAME from Wallflower"`

**Slot type toggle:**
- Two-button toggle: `"FLEX"` / `"STATIC"` using existing `Toggle` component pattern
- Default selection: FLEX
- Switches the slot list below

**Slot list:**
- Scrollable list of all 128 slots for the selected type (ScrollArea, max-h-48)
- Each row: slot number (`#NNN`, `w-12 font-mono text-xs tabular-nums`) + filename if occupied (`flex-1 text-xs truncate text-muted-foreground`) + status chip
- Status chips:
  - Empty: `text-[10px] text-muted-foreground border border-muted-foreground rounded px-1` — "empty"
  - Occupied: `text-[10px] text-[hsl(38,85%,55%)] border border-[hsl(38,85%,55%)] rounded px-1` — "occupied" (amber — same as Phase 4 occupied bank warning)
- Selected row: accent left border + `bg-[hsl(30,8%,20%)]`

**Footer:**
- "Cancel" (variant="ghost", font-mono text-xs)
- "Assign to Slot" (variant="default", font-mono text-xs) — disabled until a slot row is selected → opens dry-run preview

### Success Banner (Reuse)

Phase 5 assignment success reuses `InlineSuccessBanner` component without modification.

Message format for assignment:
`"Assigned FILENAME to Flex #NNN — 18 files updated"`

Message format for Wallflower push:
`"Pushed FILENAME to Static #NNN — 18 files updated · copied to /AUDIO/"`

Auto-dismiss: 4 seconds (unchanged from Phase 3).

### Settings — Wallflower Section

Added to an existing or new Settings panel (outside of project detail view).

- Section heading: `"WALLFLOWER"` (font-mono text-xs font-semibold uppercase text-muted-foreground, section separator style)
- Connection status row: `flex items-center gap-2 h-8`
  - Status icon: `CircleCheck` (green, hsl 140 60% 42%) when connected; `CircleMinus` (muted-foreground) when not found
  - Status text: `"Connected — wallflower.db"` or `"Not connected"` (font-mono text-xs)
- DB path row (when connected): full path in text-xs text-muted-foreground, truncated with ellipsis on left
- Change button: `"Change…"` (variant="ghost", font-mono text-xs, h-8) — opens native macOS file picker filtered to `*.db` files

## Interaction States

### Assign Button (SlotRow)

| State | Visual |
|-------|--------|
| Default (empty slot) | `Upload` icon, ghost button, muted-foreground color |
| Default (occupied slot) | `Upload` icon, ghost button, muted-foreground color — identical affordance, outcome differs |
| Hover | `bg-[hsl(30,8%,20%)]` fill (ghost button hover) |
| Pending (file picker open) | Button disabled, `opacity-40 pointer-events-none` |
| Error (format incompatible) | Button re-enabled; error inline below row appears |
| Error (slot type mismatch) | Button re-enabled; slot type error inline below row appears |

### Slot Row Expand vs Assign

Existing click-on-row-body expands the detail view (crossRefs, health). Assign button (`w-8 shrink-0` column) is a distinct hit target. Both interactions must coexist without collision. Implementation note: assign button uses `e.stopPropagation()` to prevent expand trigger on click.

### Wallflower Panel Collapse/Expand

| State | Visual |
|-------|--------|
| Expanded (default) | Panel content visible, ChevronUp icon |
| Collapsed | Panel content hidden (0 height, no layout space), ChevronDown icon |
| Transition | Collapsible component handles animation — use CSS `transition-all duration-200` |
| Loading (first open) | Skeleton rows (3 × h-9) while Wallflower query resolves |

### Wallflower Search Results

| State | Visual |
|-------|--------|
| No query | All samples (up to 200) sorted by filename |
| Active query | Filtered results update after 300ms debounce |
| No results | Empty state: `"No samples match your search."` (font-mono text-xs text-muted-foreground, centered, py-8) |
| Truncated results | Count indicator below list: `"Showing 200 of N — refine your search"` (text-[10px] text-muted-foreground) |

### Slot Picker Dialog — Slot Selection

| State | Visual |
|-------|--------|
| No selection | "Assign to Slot" button disabled (opacity-40) |
| Empty slot selected | Normal selection highlight, no warning |
| Occupied slot selected | Normal selection highlight + amber "occupied" chip visible on the row |
| Selected + occupied | Warning line below list: `"Slot NNN is occupied. Existing sample will be replaced."` (text-xs text-[hsl(38,85%,55%)]) |

### Disabled States

- Assign button: `opacity-40 pointer-events-none` when device not connected (`useDeviceStore().connected === false`)
- Wallflower panel: hidden (not disabled — completely absent) when Wallflower DB unavailable
- Push button in Wallflower row: `opacity-40 pointer-events-none` when device not connected
- All primary CTAs: disabled while any operation is in progress (backup, restore, or another assignment)
