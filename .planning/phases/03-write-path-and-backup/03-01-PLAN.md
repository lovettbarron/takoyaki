-- No REFERENCES projects(id) — projects table cleared on re-index (Pitfall 3).

CREATE TABLE backups (

    project_name TEXT NOT NULL,

    change_type   TEXT NOT NULL

Helper function `copy_project_tree(src: &Path, dest: &Path, cancel_flag: &std::sync::atomic::AtomicBool, on_event: &Channel<BackupEvent>) -> Result<(Vec<CopiedFile>, u64), AppError>`:
- Use `WalkDir::new(src).follow_links(false).min_depth(1)` (T-03-03 symlink prevention)
- For each entry: check cancel_flag (Ordering::Relaxed), create directories, `std::fs::copy()` for files
- Send `BackupEvent::Progress` per file via `on_event.send()`
- Track total bytes
- If cancel_flag is set: `std::fs::remove_dir_all(&dest)`, return `Err(AppError::Cancelled(...))`
- Return vec of `CopiedFile { src: PathBuf, dest: PathBuf, relative_path: String, size_bytes: u64 }`

Helper function `verify_checksums(copied_files: &[CopiedFile]) -> bool`:
- For each CopiedFile, call `atomic::snapshot::sha256_hex(&copied.src)` and `atomic::snapshot::sha256_hex(&copied.dest)` (using the now-pub sha256_hex)
- Return false if any pair mismatches
- Log mismatches with `error!`

**Command: `backup_project`** — `#[tauri::command]` `#[specta::specta]` `pub async fn backup_project(state: tauri::State<'_, AppState>, project_id: String, label: String, on_event: Channel<BackupEvent>) -> Result<(), AppError>`:
1. Lock DB, get card_path via `db::projects::get_card_path(&db.conn, &project_id)`, get project_name from card_path (last path component of parent SETS dir entry), drop DB lock (Pitfall 4)
2. Compute destination: `backup_base_dir().join(&project_name).join(format!("{}_{}", format_timestamp(), label))` (per D-02)
3. `std::fs::create_dir_all(&dest_path)` (per D-01)
4. Walk source to count files for `BackupEvent::Started`
5. Send `BackupEvent::Started { total_files, destination }`
6. Generate backup_id via `format!("{:016x}", std::hash::DefaultHasher hash of dest_path string)`
7. Lock DB, call `db::backups::insert_backup()` with status='in-progress', drop lock (D-12 — partial backup tracked in DB)
8. Reset cancel flag: `state.cancel_backup.store(false, Ordering::Relaxed)`
9. Call `copy_project_tree()` with cancel flag
10. If copy succeeds: verify checksums, lock DB, call `db::backups::mark_backup_complete()`, drop lock
11. Send `BackupEvent::Complete { files_copied, total_bytes, destination, checksum_ok }`
12. If copy fails or is cancelled: the in-progress record stays for cleanup on next launch

**Command: `restore_snapshot`** — `#[tauri::command]` `#[specta::specta]` `pub async fn restore_snapshot(state: tauri::State<'_, AppState>, backup_id: String, on_event: Channel<BackupEvent>) -> Result<(), AppError>`:
1. Lock DB, get backup dest_path via `db::backups::get_backup_dest_path()`, get card_path for the backup's project_id, drop lock
2. Verify device is connected: lock device state, check mount_point.is_some(), drop lock. Error if disconnected.
3. Create pre-restore snapshot via SnapshotEngine (D-11): collect all files in the project dir on the card, call `snapshot_engine.snapshot_files(&project_files, "pre-restore")`
4. Record the pre-restore snapshot as a backup record in SQLite (operation: "pre-restore")
5. Send `BackupEvent::Started`
6. Walk the backup directory, read each file's contents into memory
7. Write all files to the project dir via `atomic::atomic_write_batch()` — this stages on the same volume as the card (SAFE-04: FAT32 rename atomicity)
8. Send `BackupEvent::Complete`
9. Reset cancel flag

**Command: `compute_dry_run`** — `#[tauri::command]` `#[specta::specta]` `pub async fn compute_dry_run(state: tauri::State<'_, AppState>, project_id: String, operation: String, backup_id: Option<String>) -> Result<FileChangeManifest, AppError>`:
1. Lock DB, get card_path, drop lock
2. If operation == "backup": walk project dir, all files are "Added" (fresh backup destination). Set destination_path to computed backup dest. Set operation_label to "Back Up PROJECT_NAME".
3. If operation == "restore" and backup_id is Some: lock DB, get backup dest_path, get backup_files, drop lock. Walk current project dir on card. Compare: file in backup but not on card = Added, file in both with different hash = Modified, file on card but not in backup = Removed, file in both with same hash = Unchanged. Set operation_label to "Restore Snapshot -- TIMESTAMP".
4. Return FileChangeManifest with counts and entries
5. This function MUST NOT modify any files (SAFE-07)
