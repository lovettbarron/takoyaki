**`extract_slot_paths(project_work_bytes: &[u8]) -> Vec<SlotPath>`**
- Parse the bytes as UTF-8 lossy text
- Iterate lines. Track current slot type via `TYPE=FLEX` or `TYPE=STATIC` inline discriminators (NOT bracketed section headers -- see RESEARCH.md A1)
- Track current slot number via `SLOT=NNN` lines
- Capture `PATH=<value>` lines into `SlotPath { slot_type, slot_number, path }`
- `SlotType` is a simple enum: `Flex`, `Static` (derive Clone, Copy, Debug, PartialEq, Eq, Serialize, Type)
- `SlotPath` struct: `pub slot_type: SlotType, pub slot_number: u8, pub path: String` (derive Debug, Clone, Serialize, Type)
- Return Vec ordered by parse order

**`rewrite_slot_path(raw: &[u8], slot_type: SlotType, slot_number: u8, new_path: &str) -> Vec<u8>`**
- Parse text, find the PATH= line for the given slot_type+slot_number combination
- Replace ONLY the PATH= value on that line, preserving all other content byte-for-byte
- If the slot is not found, return raw unchanged
- Return the full modified content as Vec<u8>

**`validate_ot_name(name: &str) -> Result<(), AppError>`**
- Reject empty names: `AppError::Parse("OT name cannot be empty".to_string())`
- Reject names longer than 16 characters: `AppError::Parse("OT name exceeds 16 character limit".to_string())`
- Reject names with chars outside A-Z, 0-9, underscore: `AppError::Parse("OT name must contain only A-Z, 0-9, underscore".to_string())`
- Return Ok(()) for valid names
- Note: lowercase a-z should also be accepted (OT displays as uppercase but filesystem may store lowercase)

**`pub fn rename_project(project_dir: &Path, new_name: &str) -> Result<PathBuf, AppError>`**
- Call `project_work::validate_ot_name(new_name)?` first
- Compute new_dir = project_dir.parent().join(new_name)
- Check if new_dir already exists: return `AppError::Io(format!("Directory {} already exists", new_name))` if so
- Call `std::fs::rename(project_dir, &new_dir)?` -- both are under /SETS/ on the same volume, so same-filesystem rename is safe
- Note: project.work has NO internal NAME= field (RESEARCH.md A3 -- verified against ot-tools-io). The directory name IS the project name. No binary file modification needed.
