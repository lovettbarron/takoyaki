## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, separator dots, inline padding |
| sm | 8px | Compact element spacing, button inner gap |
| md | 16px | Default element spacing, card padding, toolbar padding |
| lg | 24px | Section padding, dialog internal spacing |
| xl | 32px | Layout gaps between major areas |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Toolbar button height: 32px (h-8), matching Phase 3 MetadataHeader Back Up button
- Bank grid cell: 48px × 48px (w-12 h-12), matching Phase 2 BankGridCell established pattern
- Touch targets (interactive controls): minimum 44px per WCAG 2.5.5 — sidebar buttons already enforce this

Source: `MetadataHeader.tsx` (h-8, h-12 patterns), `BankGridCell.tsx` (w-12 h-12), `sidebar-nav.tsx` (44px enforcement per STATE.md Plan 01-06 decision).

## Component Inventory (Phase 4 New Components)

### Toolbar Additions to MetadataHeader

Three new toolbar buttons added alongside the existing "Back Up" button in `MetadataHeader.tsx`:

| Button | Icon | Variant | Size | Condition |
|--------|------|---------|------|-----------|
| Rename | `Pencil` (lucide) | ghost | sm (h-8) | Always visible |
| Duplicate | `Copy` (lucide) | ghost | sm (h-8) | Always visible |
| Export | `PackageOpen` (lucide) | ghost | sm (h-8) | Always visible |
| Back Up | `Archive` (lucide) | default | sm (h-8) | Existing — unchanged |

Layout: `flex items-center gap-2` in the right cluster of MetadataHeader. Rename/Duplicate/Export use `variant="ghost"` to visually subordinate them to the primary Back Up action.

### Rename Inline Edit

Triggered by clicking the Rename toolbar button. The project name Display span in MetadataHeader transforms into an inline `<input>`:

- Input replaces the `<span className="font-mono text-2xl font-semibold">` element
- Width: auto-sized to content (`min-w-32 max-w-xs`)
- On confirm: Enter key or blur triggers dry-run preview modal
- On cancel: Escape key restores original name, no preview
- Real-time validation: OT-legal characters only (A–Z, 0–9, underscore). Invalid characters shown with red border (`border-destructive`) and input blocked — no error toast for single-keystroke events
- Character limit: 16 characters maximum (OT project name field limit — confirmed in binary spec)
- After Enter: dry-run preview modal opens (reuses DryRunModal component), operation label "Rename PROJECT_NAME"

### Bank Copy Context Menu

Right-click on a populated BankGridCell opens a context menu with single item: "Copy to project..."

- Use shadcn `DropdownMenu` (already in registry) positioned at cursor
- Menu only appears on populated banks (existing `populated` prop gate)
- Empty banks: no context menu on right-click
- Menu item: `Copy to project...` with `ArrowRightFromLine` lucide icon

### Bank Copy Picker Dialog (Two-Step)

New dialog component: `BankCopyPickerDialog`. Two-step flow contained in a single Dialog:

**Step 1 — Select target project:**
- Dialog title: "Copy Bank to Project" (font-mono text-base semibold)
- List of all indexed projects, scrollable (ScrollArea, max-h-64)
- Each row: project name (text-sm) + metadata strip (tempo, bank count, text-xs text-muted-foreground)
- Selected row: `bg-[hsl(30,8%,20%)]` background + accent left border `border-l-2 border-[hsl(38,85%,55%)]`
- "Next" button (variant="default") advances to Step 2
- "Cancel" button (variant="ghost") dismisses

**Step 2 — Select target bank slot:**
- Dialog title: "Select Target Slot in PROJECT_NAME" (font-mono text-base semibold)
- 4×4 grid of bank cells (mirrors Phase 2 BankGridCell pattern, 48×48px each, w-12 h-12)
- Populated slots: dot indicator filled, clickable, shows bank number
- Empty slots: dot indicator outlined (empty circle), clickable with "Empty" label
- Currently source bank slot is indicated with a muted label "source" (not selectable as target)
- If target slot is populated: warning text appears below grid — "Bank NN is occupied. Existing content will be overwritten." (text-xs text-[hsl(38,85%,55%)])
- "Copy" button (variant="default") → triggers dry-run preview
- "Back" button (variant="ghost") returns to Step 1

### Export Progress

Reuses `BackupProgressView` pattern (already built in Phase 3) with:
- Operation label: "Exporting PROJECT_NAME"
- File counter: "N files · N MB"
- Indeterminate progress bar during zip assembly
- On completion: inline success banner (reuses `InlineSuccessBanner` component)

## Interaction States

### Rename Inline Edit
- **Default:** Span with Display typography, no edit affordance visible
- **Hover (toolbar Rename button):** Ghost button becomes visible at md opacity (toolbar is always visible, no hover-to-reveal)
- **Active (editing):** Span replaced by input, autofocused, amber ring (`ring-ring`) on focus
- **Invalid:** Red border `border-destructive`, character blocked
- **Confirming:** Input disabled, spinner (Loader2 lucide, animate-spin) replaces button row
- **Success:** Input reverts to span with new name, success banner appears

### Bank Grid Cell (Phase 4 additions)
- **Right-click populated:** Context menu appears immediately
- **Right-click empty:** No effect (consistent with populated-only interaction contract)
- **Drag:** Not supported in Phase 4

### Bank Copy Picker — Step 2 Conflict
- **Hash match (unambiguous skip):** No UI — silently skipped, reflected in dry-run Added/Unchanged count
- **Missing file (auto-copy):** No UI — reflected in dry-run Added count
- **Hash mismatch (true conflict):** Each conflicting file surfaced in dry-run modal as a special "Conflict" row with three-option resolution. Conflict rows appear at top of the file list, color: `text-[hsl(38,85%,55%)]` (amber). Resolution dropdown inline per row.

### Disabled States
- Toolbar Rename/Duplicate/Export: disabled when no project selected (`opacity-40 pointer-events-none`)
- Bank Copy context menu: only on populated cells (enforced by existing `populated` prop)
- All primary CTAs: disabled while an operation is in progress
