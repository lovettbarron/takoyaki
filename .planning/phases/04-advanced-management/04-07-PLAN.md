<objective>
Add a conflict resolution step to the bank copy flow so users can choose per-conflict how to handle hash-mismatch sample files (keep-target, use-source, or rename-incoming) before the operation is applied.

Purpose: The Rust backend fully implements three conflict resolution strategies, but the frontend passes an empty `{}` to `copyBank`, silently defaulting all conflicts to "keep-target". This closes the SMPL-02 gap where conflicts are "surfaced" in the dry-run but cannot be "resolved" by the user.
Output: ConflictResolutionDialog component, updated page.tsx bank-copy flow, Rust FileChangeManifest extended with conflict details.
</objective>

The new flow inserts a conflict resolution step between 3 and 4:

Add state:
```typescript
const [conflictDialogOpen, setConflictDialogOpen] = useState(false);
const [pendingConflictResolutions, setPendingConflictResolutions] = useState<Record<string, string>>({});
```

Modify `handleMgmtDryRunApply`:
- When `mgmtOperation === "bank-copy"` AND `mgmtDryRunManifest.conflictDetails.length > 0`:
  - Do NOT proceed to execute. Instead:
  - Close the dry-run modal (`mgmtSetDryRunManifest(null)`)
  - Open the conflict resolution dialog (`setConflictDialogOpen(true)`)
  - Store the conflicts from `mgmtDryRunManifest.conflictDetails` in the management store via `mgmtSetConflicts` (map the `conflictDetails` array to `ConflictEntry[]` format with `resolution: null`)
  - Return early (do not call copyBank yet)
- When `mgmtOperation === "bank-copy"` AND `conflictDetails` is empty (or for all other operations): proceed as currently implemented

Add `handleConflictResolve` callback:
```typescript
function handleConflictResolve(resolutions: Record<string, ConflictResolution>) {
  setConflictDialogOpen(false);
  setPendingConflictResolutions(resolutions);
  // Now proceed with the actual bank copy using the resolved conflicts
  executeBankCopy(resolutions);
}
```

Extract the bank-copy execution from `handleMgmtDryRunApply` into a helper function `executeBankCopy(resolutions: Record<string, string>)` so it can be called both:
- Directly from handleMgmtDryRunApply when there are no conflicts (pass `{}`)
- From handleConflictResolve when conflicts are resolved (pass the resolution map)

The `executeBankCopy` function contains the existing bank-copy case from handleMgmtDryRunApply, but uses the `resolutions` parameter instead of hardcoded `{}`.

Add conflict cancel handler:
```typescript
function handleConflictCancel() {

  mgmtReset();
}
```
