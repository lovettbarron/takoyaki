use crate::error::AppError;

**`pub fn export_project(project_dir: &Path, card_volume_path: &Path, export_dest: &Path) -> Result<ExportResult, AppError>`**

- Read project.work bytes from project_dir
- Extract all slot paths via `project_work::extract_slot_paths()`
- Resolve each slot path to absolute audio path via `resolve_ot_path(card_volume_path, &slot.path)`
- Collect unique audio files (deduplicate by absolute path)
- Create the zip at export_dest using `ZipWriter::new(std::fs::File::create(export_dest)?)`
- Set compression options:
  - `opts_audio = SimpleFileOptions::default().compression_method(CompressionMethod::Stored)` -- WAV/AIFF already compressed, Stored is correct per RESEARCH.md
  - `opts_text = SimpleFileOptions::default().compression_method(CompressionMethod::Deflated)` -- project.work/bank files compress well
- Add the project directory tree under `SETS/{project_name}/`:
  - Use `WalkDir::new(project_dir).follow_links(false)` to traverse
  - For each file entry, compute relative path from project_dir's parent (the SETS dir), creating `SETS/{project_name}/project.work`, `SETS/{project_name}/bank01.work`, etc.
  - For directories, use `zip.add_directory()`
  - For files: detect audio by extension (`.wav`, `.aif`, `.aiff`) to pick opts_audio vs opts_text. Use `zip.start_file()` then `std::io::copy()` from File reader.
- Add audio files under `AUDIO/`:
  - For each unique resolved audio path, add as `AUDIO/{filename}` using opts_audio
  - For each audio file, check for .ot sidecar (same stem + `.ot` extension per RESEARCH.md A2, D-05): if exists, add as `AUDIO/{filename}.ot` using opts_text
- **CRITICAL: Call `zip.finish()?` before returning** (Pitfall 2 -- without finish(), central directory is never written and zip is corrupt)
- Return `ExportResult { zip_path: export_dest.to_path_buf(), files_exported: usize, total_bytes: u64 }`

**`pub fn compute_export_dest(project_name: &str) -> PathBuf`** per D-06:
- Base: `dirs::home_dir().unwrap_or(PathBuf::from(".")).join("takoyaki").join("exports")`
- Create dir if not exists: `std::fs::create_dir_all(&base)?`
- Filename: `{project_name}_{timestamp}.zip` where timestamp is seconds since epoch via `std::time::SystemTime::now().duration_since(UNIX_EPOCH).unwrap().as_secs()`
- Return base.join(filename)

**`pub struct ExportResult`**: `pub zip_path: PathBuf, pub files_exported: usize, pub total_bytes: u64` (derive Debug, Serialize, Type)

**`pub fn compute_bank_copy_conflicts(source_project_dir: &Path, target_project_dir: &Path, card_volume_path: &Path) -> Result<BankCopyAnalysis, AppError>`**
- Read project.work from both source and target project dirs
- Extract slot paths from both
- For each source slot:
  - Resolve source audio path via resolve_ot_path
  - Check corresponding slot in target (same slot_type + slot_number)
  - If target slot is empty (no PATH): mark as `AutoCopy` per D-07
  - If target slot has same filename:
    - Compute SHA-256 of both: `sha256_hex(&src_path)?` and `sha256_hex(&tgt_path)?`
    - If hashes match: mark as `Skip` per D-07
    - If hashes differ: mark as `Conflict` per D-08 -- add to conflicts list with `SlotConflict { filename, source_hash, target_hash }`
- Return `BankCopyAnalysis { auto_copy: Vec<SlotPath>, skip: Vec<SlotPath>, conflicts: Vec<SlotConflict> }`

**`pub struct BankCopyAnalysis`**: `pub auto_copy: Vec<SlotPath>, pub skip: Vec<SlotPath>, pub conflicts: Vec<SlotConflict>` (derive Debug, Serialize, Type)

**`pub fn copy_bank(source_project_dir: &Path, source_bank_index: u8, target_project_dir: &Path, target_bank_index: u8, card_volume_path: &Path, conflict_resolutions: &HashMap<String, String>) -> Result<BankCopyResult, AppError>`**
- Step 1: Copy the bank file itself. Bank files follow the naming pattern `bank{NN}.work` and `bank{NN}.strd` where NN is 2-digit zero-padded (01-16).
  - Source: `source_project_dir/bank{source_bank_index+1:02}.work` and `.strd`
  - Destination: `target_project_dir/bank{target_bank_index+1:02}.work` and `.strd`
  - Use atomic_write_batch to write both .work and .strd atomically (Pitfall 4)
- Step 2: Merge slot assignments. For each auto_copy slot from the analysis:
  - Copy audio file from source /AUDIO/ to target /AUDIO/ (std::fs::copy)
  - Copy .ot sidecar if exists
  - Rewrite target project.work PATH entry for that slot using `project_work::rewrite_slot_path()`
- Step 3: For conflict slots, apply resolution from conflict_resolutions map:
  - Key: filename (String), Value: "keep-target" | "use-source" | "rename-incoming"
  - "keep-target": do nothing (target audio file stays)
  - "use-source": overwrite target audio with source via atomic_write
  - "rename-incoming": copy source audio to /AUDIO/ with `_{n}` suffix, rewrite PATH entry in target project.work
- Step 4: Atomically write the modified target project.work AND project.strd
- Return `BankCopyResult { files_copied: usize, conflicts_resolved: usize }`

  - DB lock: acquire, extract card_path + project_name, release before file I/O (T-03-04 pattern)
  - Match on operation:
    - "duplicate": compute what files would be created (project dir + audio) -- list as Added entries
    - "rename": show old dir -> new dir as Modified entry; set operation_label to "Rename {old_name} -> {new_name}"
    - "export": list all project files + referenced audio as Added entries; set operation_label to "Export {project_name}"
    - "bank-copy": use `management::bank_copy::compute_bank_copy_conflicts()` to get analysis, convert auto_copy to Added, skip to Unchanged, conflicts to ChangeType::Conflict (extend the ChangeType enum or add a "Conflict" variant) entries
  - Prepend to operation_label: "A snapshot of the current state will be created before applying." (per UI-SPEC dry-run prefix text)

b) **`duplicate_project`**: `project_id: String, new_name: String, on_event: Channel<ManagementEvent>` -> `Result<(), AppError>`
  - DB lock: get card_path, release
  - Compute project_dir from card_path
  - Pre-operation snapshot: snapshot all files in project_dir using SnapshotEngine("pre-duplicate")
  - Send ManagementEvent::Started
  - Call `management::duplicate::duplicate_project(project_dir, &new_name, card_volume_path)?`
  - Send ManagementEvent::Complete
  - On error: send ManagementEvent::Failed

c) **`rename_project`**: `project_id: String, new_name: String` -> `Result<(), AppError>`
  - DB lock: get card_path + project_name, release
  - Pre-operation snapshot: snapshot all files in project_dir
  - Call `management::rename::rename_project(project_dir, &new_name)?` -- returns new_dir PathBuf
  - DB lock again: update projects table: `db::projects::upsert_project(&conn, &ProjectRow { id: project_id, project_name: new_name, card_path: new_dir.to_string_lossy().into_owned(), ... })`
  - No channel needed for rename (fast, synchronous)

d) **`export_project`**: `project_id: String, on_event: Channel<ManagementEvent>` -> `Result<(), AppError>`
  - DB lock: get card_path + project_name, release
  - Compute export_dest via `management::export::compute_export_dest(&project_name)`
  - No pre-operation snapshot needed (export is read-only -- nothing on the card is modified)
  - Send ManagementEvent::Started with destination = export_dest display path
  - Call `management::export::export_project(project_dir, card_volume_path, &export_dest)?`
  - Send ManagementEvent::Complete
  - On error: send ManagementEvent::Failed

e) **`copy_bank`**: `source_project_id: String, source_bank_index: u32, target_project_id: String, target_bank_index: u32, conflict_resolutions: HashMap<String, String>, on_event: Channel<ManagementEvent>` -> `Result<(), AppError>`
  - DB lock: get card_paths for both source and target projects, release
  - Pre-operation snapshot: snapshot ALL files in target project dir (Pitfall 3)
  - Send ManagementEvent::Started
  - Call `management::bank_copy::copy_bank(source_dir, source_bank_index as u8, target_dir, target_bank_index as u8, card_volume_path, &conflict_resolutions)?`
  - Send ManagementEvent::Complete
  - On error: send ManagementEvent::Failed
