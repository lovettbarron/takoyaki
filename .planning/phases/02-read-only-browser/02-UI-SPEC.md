## Spacing Scale

**Inherited unchanged from Phase 1.** Reproduced here for executor reference:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline chip spacing |
| sm | 8px | Label-to-control gaps, list item inner padding |
| md | 16px | Default element spacing, sidebar item padding |
| lg | 24px | Section padding, card inner padding |
| xl | 32px | Layout column gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level top/bottom padding |

**Phase 2 additions:**

| Context | Value | Justification |
|---------|-------|---------------|
| Table row height | 36px | Dense data table — fits 3× body lines with sm vertical padding. Not a spacing token — use `h-9` in Tailwind |
| Bank grid cell | 48px × 48px | Touch/click target matches OT hardware button feel; fits dot + label. Use `w-12 h-12` |
| Breadcrumb gap | 8px (sm) | Tight horizontal separator gap between crumb items |
| Tab bar height | 40px | Consistent with shadcn Tabs default; use `h-10` |
| Health severity badge | 4px (xs) inner padding | Compact inline status badges |
| Slot expand row | 4px (xs) top margin | Tight attachment between slot row and expanded detail |

Exceptions: Same WCAG 2.5.5 exception from Phase 1 (44px min touch target for sidebar nav items). No new exceptions.

*Sources: CONTEXT.md D-01 (dense compact table), D-06 (4×4 bank grid), Phase 1 UI-SPEC (inherited scale); Claude's Discretion (row height, cell sizing)*

## Typography

**Inherited unchanged from Phase 1.** Reproduced for executor reference:

| Role | Family | Size | Weight | Line Height | Notes |
|------|--------|------|--------|-------------|-------|
| Body | Iosevka | 14px (0.875rem) | 400 regular | 1.6 | Table cell data, slot filenames, metadata values |
| Label | Iosevka | 12px (0.75rem) | 600 semibold | 1.4 | Table column headers, tab labels, badge text, breadcrumb items |
| Heading | Iosevka | 18px (1.125rem) | 600 semibold | 1.2 | Section headings (e.g. "Flex Samples", "Banks"), tab panel headings |
| Display | Iosevka | 24px (1.5rem) | 600 semibold | 1.1 | Project name in metadata header |
| Prose | Inter | 14px (0.875rem) | 400 regular | 1.6 | Health check descriptions, error explanations, slot cross-reference text |

**Weight contract:** Regular (400) and semibold (600) only. No exceptions.

**Phase 2 typography notes:**
- Slot numbers (#001–#128) use Body + monospace character tabular nums: `font-variant-numeric: tabular-nums` for alignment
- File paths in health tab use Body Iosevka with `text-muted` color — truncated with `text-ellipsis overflow-hidden whitespace-nowrap`
- Tempo values use Body — display as `120.0 BPM` (one decimal place, space before unit)
- Bank labels ("Bank 01"–"Bank 16") use Label weight in the bank grid cells
- Health severity counts use Label weight inside severity group headers

*Sources: Phase 1 UI-SPEC (full inheritance); Claude's Discretion (tabular nums, truncation rules, tempo format)*

## Layout Contract

Phase 2 builds within the permanent chrome established in Phase 1. The 220px sidebar + flex content area + 28px titlebar are unchanged.

```
┌──────────────────────────────────────────────────────────┐
│ Titlebar: App name + ● OT-CARD (connected)               │
├──────────┬───────────────────────────────────────────────┤
│          │  [Search input ──────────────] [BPM ▾][Date ▾]│
│ Sidebar  │  ──────────────────────────────────────────── │
│ (220px)  │  NAME           BPM    BANKS    MODIFIED       │
│          │  LIVESET_01    120.0   8/16     2026-01-12     │
│ Projects │  CHORDS_V2      98.0   4/16     2026-02-03     │
│ (active) │  AMBIENT_SET   110.0   12/16    2026-03-18     │
│          │  ...                                           │
│          │                                                │
└──────────┴───────────────────────────────────────────────┘
```

- Search/filter bar: full-width bar, height 40px (h-10), `p-md` (16px) horizontal padding, `pb-sm` (8px) below bar before table
- Table header row: Label weight, muted foreground, `border-b` border
- Table data rows: Body weight, 36px row height, hover state uses Elevated surface background
- Sort indicators: up/down caret icon (Lucide `ChevronUp`/`ChevronDown`, 12px) next to active sort column header
- Default sort: last modified, descending (most recent first)
- Column widths: NAME flex-1 (takes remaining space), BPM 80px, BANKS 80px, MODIFIED 140px

### Project Detail View (with breadcrumb + metadata header + tabs)

```
┌──────────────────────────────────────────────────────────┐

│          │  Projects › LIVESET_01                        │  ← breadcrumb (Label, muted)

- Tab bar: shadcn Tabs, `border-b`, active tab has accent bottom border (2px solid), inactive tabs use Label weight muted foreground

### Banks Tab

```
│  Bank 01 ● Bank 02 ● Bank 03 ○ Bank 04 ○  │
│  Bank 05 ● Bank 06 ○ Bank 07 ○ Bank 08 ○  │
│  Bank 09 ○ Bank 10 ○ Bank 11 ○ Bank 12 ○  │
│  Bank 13 ○ Bank 14 ○ Bank 15 ○ Bank 16 ○  │
│                                            │
│  [Click a bank to drill in]                │  ← shown only when no bank selected
```

- 4×4 grid, cells 48×48px, `gap-sm` (8px) between cells
- Filled bank cell: dot rendered as filled circle (Lucide `Circle` filled or CSS `rounded-full bg-foreground`), Label weight bank number below dot
- Empty bank cell: dot rendered as empty circle (Lucide `Circle` stroke), Label weight bank number below dot in muted foreground
- Cell hover: Elevated surface background, cursor pointer only on filled cells; empty cells are `cursor-default` with no hover effect
- Cell active/selected state: accent border (1px) around selected cell

**Bank drill-down panel** (appears below grid on bank click, replaces "click a bank" hint):

```
│  Bank 01 — "BEATS_A" (bank name if set)                │

- Bank name shown in Heading weight if set, muted label "unnamed" if empty
- Parts rendered as 4-column horizontal layout
- Track rows: slot number (Label, muted, tabular nums) + machine type (Label, muted, monospace) + filename (Body, truncated)

## State Definitions

### Project List States

**No device connected:** Inherited from Phase 1 — "No Device Connected" with prose body. Projects section shows this message.

**Device connected, scanning:** Skeleton table rows (3–5 skeleton rows) replace data table while SQLite index populates. Duration < 500ms typical.

**Projects loaded (default):** Full table rendered with last-modified sort descending.

**Search active:** Table filtered in real-time. If zero results:
```
No projects match "{query}".
Clear the search to see all projects.
```

**Project list empty (no projects on card):** 
```
No projects found on this device.
The Octatrack card appears to be empty or uses an unsupported folder structure.
```

### Project Detail States

**Loading project:** Skeleton fills metadata header, tab bar renders without content, skeleton fills tab panel.

**Project loaded:** Full detail view renders. Health check begins automatically in background.

**Bank not selected (Banks tab):** 4×4 grid visible with hint row below: "Select a bank to see its parts and tracks."

**Bank selected (Banks tab):** Grid visible with selected cell highlighted; drill-down panel appears below grid.

**Health scanning:** Progress bar (indeterminate) in Health tab panel. Tab badge shows no count until complete.

**Health complete — no issues:** "All clear" centered state with green heading and scan timestamp.

**Health complete — issues found:** Tab badge shows total issue count (sum across all severities). Health tab shows grouped issue list.

### Sample Slot States

**Empty slot (hidden by default):** Not rendered unless "Show all slots" toggle is on.

**Empty slot (shown):** Muted row, no status icon, "—" in filename and rate columns.

**Occupied slot — OK:** Body foreground text, green ✓ status icon.

**Occupied slot — Error:** Body foreground text, red ✘ status icon. Row has no special background — icon alone is the signal.

**Occupied slot — Warning:** Body foreground text, amber ⚠ status icon.

**Slot expanded:** Collapsible content row in Secondary background color shows cross-reference list in Prose type.

*Sources: CONTEXT.md D-08 (hide empties default), D-11 (auto health check), D-14 (calm all clear), D-13 (inline icons)*

## Interaction Contract

| Interaction | Behavior |
|-------------|---------|
| Click project row | Navigate to project detail view; breadcrumb updates to show project name |
| Click "Projects" in breadcrumb | Return to project list view |
| Click breadcrumb bank item | Return to Banks tab at that bank's drill-down state |
| Type in search input | Filter project table in real-time (debounce 150ms); no submit required |
| Clear search input (Esc or ×) | Restore full unfiltered project list |
| Select BPM filter | Filter to projects within selected BPM range |
| Select date filter | Filter to projects modified within selected date range |
| Click table column header | Toggle sort by that column (asc → desc → none → asc); accent chevron icon indicates sort direction |
| Click tab | Switch tab panel content; no navigation change; URL hash update for deep-link |
| Click filled bank cell | Select bank; show drill-down panel below grid; cell gets accent border |
| Click same bank cell again | Deselect bank; hide drill-down panel; return to "Select a bank" hint |
| Click empty bank cell | No action; `cursor-default` |
| Hover bank cell (filled) | Tooltip: "Bank {N} — {name or 'unnamed'} · {n} patterns" |
| Hover bank cell (empty) | No tooltip |
| Click slot row | Expand/collapse cross-reference detail via Collapsible |
| Keyboard Space/Enter on slot row | Same as click — expand/collapse |
| Toggle "Show all slots" | Re-render table showing all 128 rows; toggle label changes to "Hide empty slots" |
| Hover status icon (⚠ or ✘) | Tooltip shows plain-text issue description |
| Hover long filename | Tooltip shows full untruncated path |
| Keyboard focus | Visible focus ring using accent color on all interactive elements |
| Tab key navigation | Project table rows, tab buttons, bank grid cells, slot rows, toggle — all keyboard-reachable |

*Sources: CONTEXT.md D-03 (breadcrumb navigation), D-02 (instant filter), D-05/D-06 (bank click behavior), D-08 (show all toggle), D-10 (slot expand), D-11 (health auto-run)*

**Tone rules (inherited from Phase 1, Phase 2 additions in bold):**
- No ellipsis on loading states — use skeleton or progress bar
- No exclamation points
- Hardware paths use monospace inline code formatting: `code` style within prose
- Never say "error" in the volume detection flow
- **Health issues describe the problem and state what the Octatrack requires — no jargon, no blame**
- **"All clear" not "No errors found" — positive framing**
- **Unused samples: informational tone only — not a warning, not a problem, just a note**
- **Tempo: always one decimal place ("120.0 BPM", not "120 BPM")**
- **Slot numbers: always 3-digit zero-padded (#001, not #1)**
