```rust
#[derive(Debug)]
pub enum AudioSpec {
    Wav { sample_rate: u32, bits_per_sample: u16, channels: u16 },
    Aiff { sample_rate: u32, bits_per_sample: u16, channels: u16 },
    Unknown { detected_type: Option<String> },
}

#[derive(Debug)]
pub enum FormatIssue {
    WrongSampleRate(u32),       // e.g. 48000 instead of 44100
    WrongBitDepth(u16),         // e.g. 32 instead of 16 or 24
    UnsupportedFormat(String),  // e.g. "audio/mpeg" or "unknown"
}

#[derive(Debug, serde::Serialize, Clone, specta::Type)]
#[serde(tag = "severity", rename_all = "lowercase")]
pub enum HealthIssue {
    Error {
        slot_type: String,      // "flex" or "static"
        slot_index: u8,         // 0-127
        path: String,           // full resolved path or raw path
        detail: String,         // human-readable description
    },
    Warning {
        slot_type: String,
        slot_index: u8,
        filename: String,
        detail: String,
    },
    Info {
        slot_type: String,
        slot_index: u8,
        filename: String,
        detail: String,
    },
}

#[derive(Debug, serde::Serialize, Clone, specta::Type)]
pub struct HealthCheckComplete {
    pub project_id: String,
    pub issues: Vec<HealthIssue>,
    pub scanned_at: String,
}
```

**Functions:**

1. `pub fn read_audio_spec(path: &Path) -> Result<AudioSpec, std::io::Error>` -- Detect file type by magic bytes using `infer::get_from_path()`. If WAV (mime "audio/x-wav" or extension "wav"), use `hound::WavReader::open(path)` then `.spec()` to get sample_rate, bits_per_sample, channels. If AIFF (mime "audio/aiff" or extensions "aif"/"aiff"), use `aifc::AifcReader::new()` then `.comm()` to get sample_rate, sample_size, num_channels. Otherwise return `AudioSpec::Unknown`. NEVER call `.samples()` on the WavReader -- header-only reads.

2. `pub fn check_format_compatibility(spec: &AudioSpec) -> Vec<FormatIssue>` -- For Wav/Aiff variants: flag `WrongSampleRate` if sample_rate != 44100, flag `WrongBitDepth` if bits_per_sample is not 16 and not 24. For Unknown variant: flag `UnsupportedFormat` with the detected_type string.

3. `pub fn resolve_ot_path(volume_path: &Path, raw_path: &str) -> std::path::PathBuf` -- Convert OT-style paths to macOS paths: replace backslashes with forward slashes, strip leading slash/backslash, join with volume_path. Example: volume `/Volumes/OT-CARD` + raw `\AUDIO\kick.wav` = `/Volumes/OT-CARD/AUDIO/kick.wav`.

4. `pub async fn perform_health_check(project_path: &str, volume_path: &Path, sample_slots: &[(String, u8, bool, Option<String>, Vec<(u8, u8, u8)>)]) -> Vec<HealthIssue>` -- For each occupied sample slot:
   - If `full_path` is Some, resolve it with `resolve_ot_path()` and check `std::fs::exists()`. If missing, add Error issue: "File not found: {resolved_path}". (DETC-01)
   - If file exists, call `read_audio_spec()` and `check_format_compatibility()`. For each FormatIssue, add Warning or Error issue with descriptive text matching the UI-SPEC copywriting contract. (DETC-02)
   - If the slot has zero track references (empty references vec), add Info issue: "{filename} (slot #{N}) -- assigned but not referenced by any track." (DETC-03)

   The function signature should accept structured slot data from the caller. A cleaner approach is to define an input struct:

```rust
pub struct SlotCheckInput {
    pub slot_type: String,   // "flex" or "static"
    pub slot_index: u8,
    pub occupied: bool,
    pub raw_path: Option<String>,
    pub track_references: Vec<TrackRef>,
}

pub struct TrackRef {
    pub bank_index: u8,
    pub part_index: u8,
    pub track_index: u8,
}
```

Security: In `resolve_ot_path`, after constructing the resolved path, call `std::fs::canonicalize()` on both the volume_path and the resolved path. Reject (return an error or skip) any resolved path that does not start with the canonicalized volume path. This prevents path traversal attacks from malicious OT binary files. Log the rejection with `tracing::warn!`.

```rust
use tauri::Emitter;

#[tauri::command]
#[specta::specta]
pub async fn run_health_check(
    app: tauri::AppHandle,
    state: tauri::State<'_, AppState>,
    project_id: String,
) -> Result<(), AppError> {
    // 1. Grab project path and volume path from state, then DROP the lock
    let (project_path, volume_path) = {
        let db = state.db.lock().map_err(|e| AppError::Lock(e.to_string()))?;
        let card_path = db::projects::get_card_path(&db.conn, &project_id)
            .map_err(|e| AppError::Database(e.to_string()))?;
        let vol = state.volume_path.lock()
            .map_err(|e| AppError::Lock(e.to_string()))?
            .clone()
            .ok_or_else(|| AppError::Io("No volume mounted".into()))?;
        (card_path, vol)
    };
    // Lock is dropped here — all file I/O happens outside the lock

    // 2. Spawn background task — return Ok(()) immediately
    tauri::async_runtime::spawn(async move {
        // Read sample slots from parser
        // Build SlotCheckInput list from parsed project data
        // Call perform_health_check()
        // For cross-referencing (DETC-03), read all bank files to find which
        // tracks reference each sample slot

        let issues = crate::health::perform_health_check(
            &project_path,
            &volume_path,
            &slot_inputs,  // built from parser output
        ).await;

        let result = crate::health::HealthCheckComplete {
            project_id,
            issues,
            scanned_at: chrono::Utc::now().to_rfc3339(),
        };

        app.emit("health-complete", result).unwrap_or_else(|e| {
            tracing::error!("health-complete emit failed: {e}");
        });
    });

    Ok(())
}
```

The command MUST:
- Return `Ok(())` immediately after spawning -- never block on file I/O per RESEARCH.md Pitfall 2
- Hold the DB lock only to read the project card_path and volume_path, then drop it

- Use `tauri::Emitter` trait (must be in scope for `app.emit()` to work)
- Parse the project's sample slots (flex + static) from project.work to get the list of slots to check
- Parse all 16 bank files to build the cross-reference map (which tracks reference which slots) for DETC-03 unused detection

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OT binary -> Path resolution | Sample slot paths from OT binary files are used to construct filesystem paths for existence checks |
| Frontend -> Rust IPC | project_id from frontend used to look up card_path in DB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05 | Tampering | health/mod.rs resolve_ot_path() | mitigate | canonicalize() both volume_path and resolved path; reject any resolved path that does not start with canonicalized volume root. Prevents path traversal from crafted OT binary sample paths. |
| T-02-06 | Tampering | commands/health.rs run_health_check() | mitigate | Frontend supplies project_id (opaque UUID), not a raw path. Backend resolves card_path from SQLite DB. User never controls raw file paths directly. |
| T-02-07 | Denial of Service | health/mod.rs perform_health_check() | accept | Health check reads up to 256 file headers. Each header read is ~10 microseconds. Total worst case ~3ms for headers + ~256 stat calls. Runs in background -- UI is not affected. Low risk. |
</threat_model>
