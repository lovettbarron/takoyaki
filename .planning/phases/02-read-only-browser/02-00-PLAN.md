For the WAV files, create minimal valid WAV headers using the standard RIFF/WAVE format:
- `kick_44100.wav`: RIFF header + fmt chunk (PCM, mono, 44100 Hz, 16-bit) + data chunk with 2 bytes of silence. Total ~46 bytes.
- `pad_48000.wav`: Same but sample rate = 48000 Hz.

Use a small Rust script or shell command to generate the binary WAV files. Alternatively, write them as hex literals in a helper script:

```bash
# Minimal WAV: RIFF + fmt + data
# Python one-liner to generate minimal WAV files
python3 -c "
import struct, os
def write_wav(path, sr):
    os.makedirs(os.path.dirname(path), exist_ok=True)
    ch, bps, samples = 1, 16, 1
    data_size = samples * ch * (bps // 8)
    fmt_size = 16
    file_size = 4 + (8 + fmt_size) + (8 + data_size)
    with open(path, 'wb') as f:
        f.write(b'RIFF')
        f.write(struct.pack('<I', file_size))
        f.write(b'WAVE')
        f.write(b'fmt ')
        f.write(struct.pack('<IHHIIHH', fmt_size, 1, ch, sr, sr * ch * bps // 8, ch * bps // 8, bps))
        f.write(b'data')
        f.write(struct.pack('<I', data_size))
        f.write(b'\\x00' * data_size)
write_wav('tests/fixtures/mock_ot_volume/AUDIO/kick_44100.wav', 44100)
write_wav('tests/fixtures/mock_ot_volume/AUDIO/pad_48000.wav', 48000)
"
```
