<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Binary file input to parser | Untrusted bytes from OT card files parsed by binrw — larger and more complex files than .ot |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Denial of Service | ProjectFile::from_bytes | mitigate | Validate file size against expected format size before parsing. Reject oversized or undersized input. |
| T-01-06 | Tampering | Opaque blob regions | accept | Unknown regions are preserved verbatim; no interpretation applied. If malicious bytes exist in unknown regions, they round-trip unchanged — this is by design per D-02. |
| T-01-07 | Spoofing | Wrong file type magic | mitigate | Each parser validates magic bytes at offset 0x00. A project.work file fed to BankFile::from_bytes will fail with InvalidMagic. |
</threat_model>
