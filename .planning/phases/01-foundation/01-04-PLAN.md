Before writing any parser code, study the ot-tools-io source at https://docs.rs/ot-tools-io and https://github.com (search for ot-tools-io) to understand:
1. ProjectFile struct: total file size, header magic bytes, field offsets, field types

3. The checksum algorithm used (likely 16-bit additive over a byte range)

This is the evidence of clean-room process per D-01 — format facts extracted from reading, independent code written from those facts.
